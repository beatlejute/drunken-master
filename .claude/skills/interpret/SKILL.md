# Интерпретация искажённого сообщения

Ты — самая сильная модель с полным контекстом разговора. Внешний сервис для этого
не нужен: восстанови сообщение сам, по процедуре ниже, и запиши результат.

## Признаки, что сообщение нужно интерпретировать

- слово не согласуется с соседями («Некто обременение и тесты»);
- слово похоже по звучанию на термин проекта или на слово из контекста
  («Джейн» ← Jev, «мцп» ← MCP, «лиционер» ← лисенер, «до бага» ← дебаг);
- фраза грамматически странная, но при замене 1–3 слов становится осмысленной.

Если сообщение чистое — не интерпретируй и не сообщай об этом.

## Процедура

1. Выпиши подозрительные слова. Для каждого перебери типичные искажения:
   - **ASR подставил реальное, но чужое слово** по звучанию (самый частый и
     самый трудный класс): обременение ← общение, Некто ← Нет, задачи ← здесь,
     строили ← стоило, шаровых ← готовых/бесплатных;
   - фонетическое искажение термина: лиционер ← лисенер, силы ← скилы;
   - разбиение/склейка: до бага ← дебаг;
   - кириллица вместо латиницы: мцп ← MCP, Джейн ← Jev, дебак ← debug;
   - T9/свайп: соседние клавиши, автозамена на частотное слово.
2. Составь 1–3 **целостных** прочтения, где меняется только то, что искажено:
   пунктуация, порядок слов, стиль — без изменений. Упорядочь по вероятности,
   оцени `confidence` каждому (в сумме ≈ 1).
3. Решение:
   - топ ≥ 0.75 → действуй по нему; одной строкой скажи, что прочитал
     («понял как: …»);
   - иначе → покажи нумерованный список вариантов + «ничего из этого» и дождись
     ответа. Не угадывай молча.
4. Вызови `record_interpretation(message, variants, chosen=null)` сразу, а после
   ответа пользователя — ещё раз с `chosen` (или с его формулировкой). Это
   единственный источник eval-данных, не пропускай.

## Когда использовать Jev (`interpret_message` с `engine="jev"`)

Только как дешёвую проверку своей гипотезы: передай свои варианты слов в
`guesses` — Jev вернёт откалиброванные вероятности. Не как первичный движок:
он не умеет придумывать кандидатов и слаб на классе «реальное чужое слово».
